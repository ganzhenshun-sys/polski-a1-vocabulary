# Polski A1

一份可用 iPhone Safari 学习波兰语的网页，内容取自《Polish A1 Vocabulary.pdf》。

## 包含

- 200 个原始 A1 词汇 + 63 个基础补充词（数字、颜色、生活基础）
- 50 个日常表达
- 波兰语卡片、拼写小测、收藏和发音
- 动词变位速查与 10 天学习计划
- 学习数据保存在当前设备浏览器
- HTTPS 部署时支持离线缓存和添加到 iPhone 主屏幕

## 文件

- `index.html` 页面和样式
- `data.js` 词汇与句子
- `app.js` 学习、收藏和进度逻辑
- `manifest.json` 主屏幕应用信息
- `sw.js` 离线缓存
- `icon.svg` 应用图标

## 在 Mac 上查看

在 Finder 中打开本文件夹，双击 `index.html` 可在 Safari 里预览。Xcode 可以打开并编辑这些文件；它是代码编辑器，预览网页时用 Safari。

## 发布

需要把这些文件放进一个启用了 GitHub Pages 的仓库。发布后，在 iPhone Safari 打开网站，点“分享”→“添加到主屏幕”。**仓库设为公开前请先确认。**
